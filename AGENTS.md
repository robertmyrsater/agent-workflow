# Maintaining this repository

Read `README.md` and `docs/maintaining.md` before changing this shared workflow.
Keep guidance general, concise and useful across projects. Product details,
named project owners, service accounts, runtime commands and current task status
belong in the adopting project's overlay and records.

Use reviewed changes and `CHANGELOG.md` for general improvements. Check affected
guides/templates together, preserve explicit authorization boundaries and
validate links. Independent review must identify the exact candidate. A docs
change does not authorize publication, installation, permission changes, external
messages or live operations; use the actual task's applicable authorization.

Do not include credentials, private customer evidence, raw messages, authenticated
URLs, session files or personal machine paths. Use sanitized examples and
provenance references when needed. Do not copy installer commands or tool state.

Files in `templates/` are examples for deliberate project adoption, not active
instructions for this repository or other projects. Do not propagate them,
replace global/local guidance or update a project's reviewed revision without
that project's authorized adoption. Preserve local overrides and work/company
account boundaries.
